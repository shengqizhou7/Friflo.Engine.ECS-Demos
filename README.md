# Cube Demo
本项目是一个基于[Friflo.Engine.ECS-Demos](https://github.com/friflo/Friflo.Engine.ECS-Demos)改造的ECS框架演示项目。在原有场景的基础上，引入了多种ECS实现和传统的OOP实现，便于进行性能对比和功能展示。另外从方块颜色的角度出发新增了多个特性，展示了PGD框架的独有特性。

## 重点特性

- 新增PGD、OOP多种实现方式，便于不同范式和框架的性能对比
- 新增颜色传播系统，展示PGD的Relation特性
- 新增点击热点图功能，展示PGD的Lookup特性
- 方块叠加扰流等位移，模拟真实游戏中的复杂场景
